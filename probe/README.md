# mh4uprobe (M0, read-only)

Forge PC 0.7 plugin. For each of the 110 upstream hook sites (`sites.h`, generated by
`tools/gen_sites.mjs` from `MH4U-port-to-MHGU` `module/build.py` HOOKS + `gear_hooks.txt`) it
checks the 1.4.0 word and sorts the site into bucket B1 / B2 / B3 of `DEVELOP.md` 3.5. It writes
no game memory and creates no hook.

Build: `build.bat` (MSVC x64; `FORGE_INCLUDE` = folder with `forge_pc.h`).
Install: copy `dist/mods` into the export folder. Output: `mods/0100770008DD8000/MH4U/mh4u_sites.txt`,
last line `[3] summary: words matched N/110; B1 .., B2 .., B3 ..`.

Status (2026-10-24): built warning-free; run only on a fake host (1.4.0 flat image for
`mem_read`): words matched 110/110. The bucket split needs the real export.
